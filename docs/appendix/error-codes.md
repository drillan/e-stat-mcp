# エラーコード一覧

e-Stat MCP サーバーで発生するエラーコードと対処法を解説します。

## e-Stat API エラー

### SUCCESS（0）

| 項目 | 内容 |
|------|------|
| コード | 0 |
| 意味 | 成功 |
| 対処法 | - |

### NO_DATA（1）

| 項目 | 内容 |
|------|------|
| コード | 1 |
| 意味 | 該当データなし |
| 対処法 | 検索条件を変更してください |

```
検索条件に一致するデータが見つかりませんでした。
キーワードを変更するか、検索条件を緩和してください。
```

### AUTH_ERROR（100）

| 項目 | 内容 |
|------|------|
| コード | 100 |
| 意味 | 認証エラー |
| 対処法 | E_STAT_APP_ID を確認してください |

```
認証に失敗しました。
E_STAT_APP_ID が正しく設定されているか確認してください。
```

**確認項目:**
- 環境変数 `E_STAT_APP_ID` が設定されているか
- アプリケーションIDが正しいか
- `.env` ファイルが正しく読み込まれているか

### MISSING_PARAM（101）

| 項目 | 内容 |
|------|------|
| コード | 101 |
| 意味 | 必須パラメータ不足 |
| 対処法 | 必須パラメータを指定してください |

```
必須パラメータが不足しています: statsDataId
```

**よくある原因:**
- `get_stats_data` で `stats_data_id` を指定していない
- `get_meta_info` で `stats_data_id` を指定していない

### INVALID_PARAM（102）

| 項目 | 内容 |
|------|------|
| コード | 102 |
| 意味 | パラメータ値が不正 |
| 対処法 | パラメータの値を確認してください |

```
パラメータの値が不正です: limit
```

**よくある原因:**
- `limit` が 100,000 を超えている
- `start_position` が 0 以下
- 存在しないコードを指定している

### DATA_NOT_FOUND（300）

| 項目 | 内容 |
|------|------|
| コード | 300 |
| 意味 | データが存在しない |
| 対処法 | 統計表IDやデータセットIDを確認してください |

```
指定されたデータが見つかりませんでした。
統計表IDを確認してください。
```

**よくある原因:**
- 存在しない統計表IDを指定
- 統計表が削除された
- データセットIDが間違っている

## クライアント側エラー

### NETWORK_ERROR（900）

| 項目 | 内容 |
|------|------|
| コード | 900 |
| 意味 | ネットワークエラー |
| 対処法 | ネットワーク接続を確認してください |

```
e-Stat APIへの接続に失敗しました。
ネットワーク接続を確認してください。
```

**よくある原因:**
- インターネット接続がない
- DNS解決に失敗
- タイムアウト

**対処法:**
1. インターネット接続を確認
2. しばらく待って再試行
3. `E_STAT_REQUEST_TIMEOUT_SECONDS` を長くする

### SERVER_ERROR（901）

| 項目 | 内容 |
|------|------|
| コード | 901 |
| 意味 | サーバーエラー |
| 対処法 | しばらく待って再試行してください |

```
e-Stat APIでサーバーエラーが発生しました。
しばらく待ってから再試行してください。
```

**よくある原因:**
- e-Stat API のサーバー障害
- メンテナンス中

**対処法:**
1. しばらく待って再試行
2. [e-Stat](https://www.e-stat.go.jp/) でメンテナンス情報を確認

### VALIDATION_ERROR（902）

| 項目 | 内容 |
|------|------|
| コード | 902 |
| 意味 | バリデーションエラー |
| 対処法 | APIレスポンスの形式を確認してください |

```
APIレスポンスの形式が不正です。
```

**よくある原因:**
- e-Stat API の仕様変更
- 予期しないレスポンス形式

**対処法:**
1. プロジェクトを最新版に更新
2. Issue を報告

## トラブルシューティング

### 認証エラーが続く場合

1. アプリケーションIDを再確認
2. `.env` ファイルの形式を確認（`=` の前後にスペースがないか）
3. 環境変数が正しく設定されているか確認：
   ```bash
   echo $E_STAT_APP_ID
   ```

### タイムアウトが頻発する場合

1. `E_STAT_REQUEST_TIMEOUT_SECONDS` を長くする（例: 60）
2. `E_STAT_MAX_RETRIES` を増やす（例: 5）
3. `limit` を小さくしてデータ量を減らす

### 大量データの取得に失敗する場合

1. `limit` を小さくして分割取得
2. フィルタ条件を追加して取得データを絞る
3. ページネーションを使用

## ログの確認

MCP サーバーのログでエラーの詳細を確認できます：

- **macOS**: `~/Library/Logs/Claude/mcp*.log`
- **Windows**: `%USERPROFILE%\AppData\Local\Claude\logs\mcp*.log`
- **Linux**: `~/.config/Claude/logs/mcp*.log`
