# 使用例

実践的なユースケースを紹介します。

## 基本的な使い方

### 統計表の検索

キーワードで統計表を検索します。

```
「人口」に関する統計表を5件検索してください
```

```
「労働力調査」に関する統計表を検索してください
```

### 政府統計コードで検索

特定の政府統計を指定して検索します。

```
政府統計コード「00200521」（国勢調査）の統計表を検索してください
```

```
政府統計コード「00450011」（労働力調査）の2023年の統計表を検索してください
```

### 調査年で絞り込み

特定の調査年の統計表を検索します。

```
2020年から2023年の人口に関する統計表を検索してください
```

## メタ情報の確認

統計データを取得する前に、メタ情報で構造を確認することをお勧めします。

### メタ情報の取得

```
統計表ID「0003410379」のメタ情報を取得してください
```

レスポンス例：
- `tab`: 表章事項（人口、世帯数など）
- `cat01`: 分類事項1（年齢、性別など）
- `area`: 地域（都道府県、市区町村など）
- `time`: 時間軸（年月など）

### 分類コードの確認

```
統計表ID「0003410379」のメタ情報から、地域の分類コード一覧を教えてください
```

## 統計データの取得

### 基本的なデータ取得

```
統計表ID「0003410379」の最初の10件のデータを取得してください
```

### フィルタ条件を指定

メタ情報で確認したコードを使って絞り込みます。

```
統計表ID「0003410379」から、東京都（地域コード: 13000）のデータを取得してください
```

```
統計表ID「0003410379」から、2020年のデータのみを取得してください
```

## 実践的なシナリオ

### シナリオ1: 都道府県別人口の分析

```
以下の手順で2020年の都道府県別人口データを取得してください：
1. 国勢調査の人口に関する統計表を1件検索
2. メタ情報を確認
3. 都道府県別の人口データを取得
4. 人口の多い上位5都道府県を教えてください
```

### シナリオ2: 時系列データの取得

```
労働力調査から、過去5年間の完全失業率の推移を取得してください
```

### シナリオ3: 地域比較

```
2020年国勢調査から、東京都、大阪府、愛知県の人口を比較してください
```

## データセットの活用

公開データセットは、よく使われる統計データをまとめたものです。

### データセット一覧の取得

```
公開データセットの一覧を取得して、どのようなデータが利用可能か教えてください
```

### 特定統計表のデータセット

```
統計表ID「0003410379」に関連するデータセットを確認してください
```

### データセットからデータ取得

```
データセットID「XXXX」からデータを取得してください
```

## 大量データの取得

### ページネーション

一度に取得できるデータ数には上限があります。大量データは分割して取得します。

```
統計表ID「0003410379」の全データを取得してください。
必要に応じてページネーションを使用し、start_position を変更しながら全件取得してください。
```

### 件数の確認

```
統計表ID「0003410379」のデータ総件数を確認してください
```

## Tips

### 効率的な検索のコツ

1. **まずメタ情報を確認**: データ構造を理解してから取得
2. **絞り込みを活用**: 必要なデータのみ取得してレスポンス時間を短縮
3. **キャッシュを活用**: 同じクエリは自動的にキャッシュされます

### よく使う政府統計コード

| コード | 統計名 |
|--------|--------|
| `00200521` | 国勢調査 |
| `00200522` | 人口推計 |
| `00450011` | 労働力調査 |
| `00100401` | 消費者物価指数 |
| `00500201` | 家計調査 |
