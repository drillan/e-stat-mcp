# get_stats_data

統計表からデータを取得するツールです。

## 概要

統計表IDを指定して、実際の統計データを取得します。フィルタ条件を指定して、必要なデータのみを取得できます。

## パラメータ

| パラメータ | 型 | 必須 | デフォルト | 説明 |
|-----------|------|------|----------|------|
| `stats_data_id` | str | **必須** | - | 統計表ID（search_stats で取得） |
| `cd_tab` | str | 任意 | null | 表章事項コード |
| `cd_cat01` | str | 任意 | null | 分類事項コード01 |
| `cd_cat02` | str | 任意 | null | 分類事項コード02 |
| `cd_area` | str | 任意 | null | 地域コード |
| `cd_time` | str | 任意 | null | 時間軸コード |
| `limit` | int | 任意 | 10,000 | 取得件数上限（最大: 100,000） |
| `start_position` | int | 任意 | 1 | 取得開始位置 |

```{tip}
フィルタコードは `get_meta_info` で確認できます。
```

## 戻り値

```json
{
  "total_count": 12345,
  "returned_count": 100,
  "data": [...]
}
```

### data の各要素

| フィールド | 型 | 説明 |
|-----------|------|------|
| `tab_name` | str | 表章事項名 |
| `category_names` | dict | 分類項目名（{cat01: "...", cat02: "..."}） |
| `area_name` | str | 地域名 |
| `time_name` | str | 時点名 |
| `value` | float | 統計値（数値、欠損の場合は null） |
| `value_raw` | str | 統計値（生の文字列） |
| `unit` | str | 単位 |

## 使用例

### 基本的なデータ取得

```
統計表ID「0003410379」の最初の10件のデータを取得してください
```

→ `get_stats_data(stats_data_id="0003410379", limit=10)`

レスポンス例：
```
total_count: 47
returned_count: 10

1. 表章事項: 人口（総数）
   地域: 北海道
   時点: 2020年
   値: 5,224,614 人

2. 表章事項: 人口（総数）
   地域: 青森県
   時点: 2020年
   値: 1,237,984 人
...
```

### フィルタ条件を指定

地域コードでフィルタ：

```
統計表ID「0003410379」から東京都（地域コード: 13000）のデータを取得してください
```

→ `get_stats_data(stats_data_id="0003410379", cd_area="13000")`

時間軸でフィルタ：

```
統計表ID「0003410379」から2020年のデータを取得してください
```

→ `get_stats_data(stats_data_id="0003410379", cd_time="2020000000")`

複数条件の組み合わせ：

```
統計表ID「0003410379」から、東京都の2020年のデータを取得してください
```

→ `get_stats_data(stats_data_id="0003410379", cd_area="13000", cd_time="2020000000")`

### ワイルドカード

コードに `*` を含めてワイルドカード検索ができます：

```
関東地方（地域コード: 1*）のデータを取得
```

→ `get_stats_data(stats_data_id="...", cd_area="1*")`

### 大量データの取得

```
統計表ID「0003410379」の全データを取得してください。
データ件数が多い場合は、ページネーションを使用してください。
```

1回目: `get_stats_data(stats_data_id="0003410379", limit=10000, start_position=1)`
→ total_count: 47, returned_count: 47 （47件なので1回で完了）

大量データの場合:
```
1回目: start_position=1, limit=10000 → 10000件取得
2回目: start_position=10001, limit=10000 → 10000件取得
...
```

## 欠損値の扱い

統計データには欠損値が含まれることがあります：

| 生の値 | 意味 | `value` フィールド |
|--------|------|-------------------|
| `-` | 該当なし | null |
| `...` | 不詳 | null |
| `x` | 秘匿 | null |
| `*` | 参考値 | null |

欠損値の場合、`value` は `null` になりますが、`value_raw` には元の文字列が保持されます。

## エラーケース

### 統計表が存在しない

```
指定された統計表ID「XXXX」が見つかりません。
search_stats で正しいIDを確認してください。
```

### データなし

フィルタ条件に一致するデータがない場合：

```json
{
  "total_count": 0,
  "returned_count": 0,
  "data": []
}
```

## パフォーマンスのヒント

1. **フィルタを活用**: 必要なデータのみ取得するとレスポンスが速くなります
2. **メタ情報を先に確認**: `get_meta_info` で正しいコードを確認してからデータ取得
3. **ページネーション**: 大量データは分割して取得
