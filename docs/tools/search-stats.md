# search_stats

統計表を検索するツールです。

## 概要

キーワード、政府統計コード、調査年で統計表を検索し、一覧を取得します。

## パラメータ

| パラメータ | 型 | 必須 | デフォルト | 説明 |
|-----------|------|------|----------|------|
| `keyword` | str | 任意 | null | 検索キーワード（統計表名、作成機関名などから検索） |
| `stats_code` | str | 任意 | null | 政府統計コード（例: "00200521" は国勢調査） |
| `survey_years` | str | 任意 | null | 調査年の範囲（例: "2020" または "2020-2023"） |
| `limit` | int | 任意 | 100 | 取得件数上限（最大: 100,000） |
| `start_position` | int | 任意 | 1 | 取得開始位置 |

```{note}
`keyword` と `stats_code` の両方を指定すると、AND条件で検索されます。
```

## 戻り値

検索結果のリスト。各要素は以下の構造です：

| フィールド | 型 | 説明 |
|-----------|------|------|
| `table_id` | str | 統計表ID（get_stats_data などで使用） |
| `table_name` | str | 統計表名称 |
| `stat_name` | str | 政府統計名称 |
| `survey_date` | str | 調査年月 |
| `gov_org` | str | 作成機関 |

## 使用例

### キーワード検索

```
「人口」に関する統計表を5件検索してください
```

→ Claude が `search_stats(keyword="人口", limit=5)` を呼び出します。

レスポンス例：
```
1. table_id: 0003410379
   table_name: 都道府県別人口及び世帯数
   stat_name: 国勢調査
   survey_date: 2020年
   gov_org: 総務省

2. table_id: 0003215423
   table_name: 人口推計（各年10月1日現在）
   stat_name: 人口推計
   survey_date: 2023年
   gov_org: 総務省
...
```

### 政府統計コードで検索

```
政府統計コード「00200521」の統計表を検索してください
```

→ `search_stats(stats_code="00200521")`

### 調査年で絞り込み

```
2020年から2023年の労働力調査を検索してください
```

→ `search_stats(keyword="労働力調査", survey_years="2020-2023")`

### ページネーション

```
人口に関する統計表を100件取得してください。
次に101件目から200件目を取得してください。
```

→ 1回目: `search_stats(keyword="人口", limit=100, start_position=1)`
→ 2回目: `search_stats(keyword="人口", limit=100, start_position=101)`

## よく使う政府統計コード

| コード | 統計名 |
|--------|--------|
| `00200521` | 国勢調査 |
| `00200522` | 人口推計 |
| `00200523` | 住民基本台帳人口移動報告 |
| `00450011` | 労働力調査 |
| `00100401` | 消費者物価指数 |
| `00500201` | 家計調査 |
| `00200603` | 経済センサス |

## エラーケース

### データなし

検索条件に一致する統計表がない場合、空のリストが返されます。

```
検索条件に一致する統計表が見つかりませんでした。
キーワードを変更するか、検索条件を緩和してください。
```

### パラメータエラー

`limit` が上限を超えた場合など：

```
パラメータが不正です: limit は 100,000 以下にしてください。
```
