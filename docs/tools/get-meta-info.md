# get_meta_info

統計表のメタ情報を取得するツールです。

## 概要

統計表の構造（分類項目、地域、時間軸など）を取得します。`get_stats_data` でフィルタ条件を指定する際に必要なコードを確認できます。

## パラメータ

| パラメータ | 型 | 必須 | デフォルト | 説明 |
|-----------|------|------|----------|------|
| `stats_data_id` | str | **必須** | - | 統計表ID |

## 戻り値

分類情報のリスト。各要素は以下の構造です：

| フィールド | 型 | 説明 |
|-----------|------|------|
| `class_id` | str | 分類ID（tab, cat01, cat02, area, time など） |
| `class_name` | str | 分類名（表章事項、地域、時間軸 など） |
| `items` | list | 分類項目のリスト |

### items の各要素

| フィールド | 型 | 説明 |
|-----------|------|------|
| `code` | str | 分類項目コード（フィルタで使用） |
| `name` | str | 分類項目名 |
| `level` | str | 階層レベル（任意） |
| `unit` | str | 単位（任意） |

## 使用例

### メタ情報の取得

```
統計表ID「0003410379」のメタ情報を取得してください
```

→ `get_meta_info(stats_data_id="0003410379")`

レスポンス例：
```
class_id: tab
class_name: 表章事項
items:
  - code: 001, name: 人口（総数）
  - code: 002, name: 世帯数

class_id: area
class_name: 地域
items:
  - code: 00000, name: 全国
  - code: 01000, name: 北海道
  - code: 02000, name: 青森県
  - code: 13000, name: 東京都
  ...

class_id: time
class_name: 時間軸（年次）
items:
  - code: 2020000000, name: 2020年
  - code: 2015000000, name: 2015年
  ...
```

### 特定の分類項目を確認

```
統計表ID「0003410379」のメタ情報から、地域の分類コード一覧を教えてください
```

### フィルタ条件の確認

```
統計表ID「0003410379」のメタ情報を確認して、東京都のデータを取得するためのコードを教えてください
```

→ メタ情報から `area` の `code: 13000` が東京都であることを確認
→ `get_stats_data(stats_data_id="0003410379", cd_area="13000")` でデータ取得

## 分類IDの種類

| 分類ID | 説明 | フィルタパラメータ |
|--------|------|-------------------|
| `tab` | 表章事項（人口、世帯数など） | `cd_tab` |
| `cat01` | 分類事項1（年齢、性別など） | `cd_cat01` |
| `cat02` | 分類事項2 | `cd_cat02` |
| `cat03` | 分類事項3 | - |
| `area` | 地域 | `cd_area` |
| `time` | 時間軸 | `cd_time` |

```{note}
統計表によって存在する分類IDは異なります。
```

## 階層構造

地域などは階層構造を持つ場合があります：

```
level: 1, code: 00000, name: 全国
level: 2, code: 01000, name: 北海道
level: 3, code: 01100, name: 札幌市
```

`level` が深いほど詳細な地域を表します。

## ワークフロー

メタ情報を使った典型的なワークフロー：

```{mermaid}
flowchart TD
    A[search_stats] --> B[table_id を取得]
    B --> C[get_meta_info]
    C --> D{分類項目を確認}
    D --> E[必要なコードを特定]
    E --> F[get_stats_data<br/>フィルタ条件を指定]
```

### 実践例

```
以下の手順で2020年の東京都の人口を取得してください：
1. 国勢調査の人口統計表を検索
2. メタ情報で東京都のコードを確認
3. 東京都の2020年のデータを取得
```

```
指定された統計表ID「XXXX」が見つかりません。
```
